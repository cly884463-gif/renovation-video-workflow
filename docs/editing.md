# 选镜与返修验收

## 按实际内容而非文件名判断

- 卫生间、厨房、阳台、客厅分别确认；洗衣机和窗户不证明是厨房，厨房需辨认灶台、橱柜、水槽等空间证据。
- 产品桶标、材料状态与具体项目授权一起核对。材料名称不明的画面不作为目标材料施工事实。
- 垃圾清运用装袋、搬运、装车等画面；家具保护用实际覆膜和包裹画面。
- “叔叔阿姨/老人”可选合适老人镜头，但不凭外貌编造客户关系。
- 同空间前后对比通过门窗、结构、布局核对。读到“变成这样”时切到改造后画面，使用自然短叠化/合适转场，保留真实运动余量。

## 运镜意图

| 运镜/动作 | 适配用途 |
|---|---|
| 拉近、局部特写 | 材料质感、施工细节 |
| 拉远、全景 | 完工整体效果 |
| 开门 | 空间切换、转场 |
| 人物手势 | 动作匹配转场、引导或收尾 |
| 连续近景 | 完整批刮工序、施工流畅程度 |
| 延时摄影 | 工期短、快速施工等短语句节奏 |

保持动作完整；长开头可使用连续讲解镜头，避免为凑镜头数连续切不同人像。曝光丢失细节的素材优先换掉，不靠压暗掩盖。

## 字幕重点

按实际语义选择多个黄色重点，例如：发黑发霉、不拆不砸、耐压耐磨、旧房翻新、厨房翻新、卫生间翻新、小红心、点个赞、费时费力、一体无缝、防霉防潮、环保、无甲醛、省钱、头像。出现关键词不等于产品宣称已经验证；文字适用依据仍须检查。

字幕显示不带标点，配音稿保留标点；字幕换页与镜头切换分别安排。不要把词组拆成不自然气口。

## 重复检查

单条、同批、近期三个层次分别核对准确源、房间、动作和相似构图。更换截取位置、裁切、变速、文件名不算新素材。使用 private 排除清单维护高频源，不将内部客户和源路径放进公开规则。允许复用时记录理由，不能把哈希不同称作画面全新。

## 返修清单

1. 明确当前有效版本和问题时间码。
2. 保留旧输入/成片，生成新版本。
3. 声音变化同步字幕和镜头；画面变化复核材料、房间及前后关系。
4. 检查受影响准确区间，再检查整条连续成片。
5. 按新 SHA 记录批准；投递前后校验复制 SHA。
